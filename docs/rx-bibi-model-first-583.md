# RX BIBI #583 — opcjonalny model-first w istniejącym czacie

Zidentyfikowano przyczynę: `/api/rx/client/chat` domyślnie wybiera lokalny planer; model jest wywoływany wyłącznie po prefiksie `Zapytaj model:`. Dodano opcjonalną flagę `RX_BIBI_CLIENT_MODEL_FIRST=true` do własnego serwera RX CLOUD, działającą tylko razem z `RX_BIBI_MODEL_ENABLED=true` i skonfigurowanym lokalnym serwisem `RX_BIBI_MODEL_PORT`. Bez tej flagi zachowanie produkcyjne pozostaje bez zmian. Żadne sekrety ani prywatna pamięć nie są wysyłane do modelu; zapytania o prywatne dane administracyjne nadal są blokowane przed trybem model-first. Błędy modelu powodują powrót do planera. Model to prosty klasyfikator tokenowy, nie generatywny LLM. Nie wykonano wdrożenia; zmiana flag wymaga osobnego zatwierdzenia i testu infrastruktury.
